# Taste Loop 🍽️
**School Web Design Project — Recipe Discovery Prototype**

Taste Loop is a responsive web prototype that explores a “cook by playing” idea: instead of endless scrolling, users browse recipes through a clean homepage, simple navigation, and interactive discovery elements.

## Overview
This project focuses on front-end layout, UI design, and interaction patterns for a recipe discovery website. It was built as a prototype to demonstrate structure and user experience rather than complete, accurate content.

---

## Tech Stack
**HTML5 + CSS3 + Vanilla JavaScript**  
(Static front-end prototype — no APIs, no backend.)

---

## Prototype Note (Important)
The images shown on the pages **do not reliably match** the labels/titles displayed. This is intentional for the prototype stage: visual placeholders were used to test layout and interactions, not final content accuracy.

---

## How to Run
Open `index.html` in your browser.  
For development, you can use a local server (e.g., VS Code Live Server).
