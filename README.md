<h1 align="center">Taste Loop 🍽️</h1>
<p align="center"><b>School Web Design Project — Recipe Discovery Prototype</b></p>

<p align="center">
Taste Loop is a responsive web prototype that explores a <b>“cook by playing”</b> idea. Instead of endless scrolling, users browse recipes through a clean homepage, simple navigation, and interactive discovery elements.
</p>

<p align="center">
  🔗 <b>Live Demo:</b> https://cuongme.github.io/tasteloop-web/
</p>

---

## 🌿 Overview
This project focuses on **front-end layout**, **UI design**, and **interaction patterns** for a recipe discovery website. It is a prototype created to demonstrate structure and user experience rather than complete, accurate content.

## 🧱 Tech Stack
**HTML5 • CSS3 • Vanilla JavaScript**  
Static front-end prototype — **no APIs** and **no backend**.

## ⚠️ Prototype Note
The images shown on the pages **do not reliably match** the labels/titles displayed. This is intentional for the prototype stage: visual placeholders were used to test layout and interactions, not final content accuracy.
